# Hi, I'm Ethan Parmer 👋

**Data engineer building compliant, production-grade data platforms on Databricks for regulated life sciences manufacturing.**

I work where data engineering meets GxP: turning manufacturing, quality, and ERP data into trustworthy, auditable pipelines that hold up to validation and 21 CFR Part 11 scrutiny. Before engineering, I spent a decade in healthcare and biotech finance and analytics, so I build with the business outcome in mind, not just the pipeline.

## 🔧 What I build

- **Compliant lakehouse patterns:** audit trails, data integrity controls, and validation-ready pipelines on Delta Lake and Unity Catalog
- **Real-time manufacturing data:** streaming MES and event data through Databricks into ERP systems
- **Tooling that makes validation less painful:** turning lineage, table history, and pipeline definitions into evidence auditors can actually use
